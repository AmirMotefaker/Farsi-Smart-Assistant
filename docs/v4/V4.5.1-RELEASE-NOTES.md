# Farsi Smart Assistant v4.5.1 — Store Compatibility Hotfix

## Why

The Store-publication audit found that packaged icon filenames/manifest slots did not match their real PNG dimensions.

Previous v4.5.0 package:
- icon16.png = 16x16
- icon48.png = 32x32
- icon128.png = 192x192

## Changes

- icon16.png remains 16x16
- add icon32.png = 32x32
- regenerate icon48.png = 48x48
- regenerate icon128.png = 128x128
- 128px Store icon uses centered artwork with maximum 96px visible content
- manifest and package version -> v4.5.1
- Store audit verifies every declared icon's actual PNG dimensions
- Store-publication docs moved to v4.5.1
- release-readiness regression made version-safe

## Scope safety

- no correction-engine behavior change
- no permission expansion
- no remote runtime dependency added
