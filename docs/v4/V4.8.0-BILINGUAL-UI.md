# v4.8.0 — Bilingual FA/EN Product UI

## Scope

v4.8.0 localizes the product interface without changing the correction engine's language-intent behavior.

## Product contract

- Persian remains the default UI locale.
- Popup exposes a compact `FA | EN` segmented control directly beside Dark Mode.
- UI preference persists in `chrome.storage.sync` as `uiLanguage`.
- Persian uses `lang=fa` + `dir=rtl`.
- English uses `lang=en` + `dir=ltr`.
- Popup, Settings, Site Management, dynamic status/confirmation text, accessibility labels, and inline Correction/Undo surfaces share one local `ui_i18n.js` catalog.
- Smart Auto, keyboard intent, Finglish, normalization, personal dictionary, and correction decisions are not gated by `uiLanguage`.
