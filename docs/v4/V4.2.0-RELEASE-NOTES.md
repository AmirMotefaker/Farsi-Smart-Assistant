## What changed

- Range-local correction instead of whole-field replacement.
- Current-token correction around a collapsed caret.
- Explicit-selection correction without requiring new typing.
- Caret restoration immediately after accepted replacement.
- Native `insertText` path verified with Chromium Undo.
- Range-local contenteditable editing with surrounding DOM preserved.
- Controlled-input event propagation preserved.
- Stale suggestions are rejected after newer field changes.
- Dynamic-field, sensitive-field and no-submit invariants preserved.
- M1 short-phrase fallback remains available.

## Editing examples

- `hello sghl world` → `hello سلام world`
- `before ugd after` → `before علی after`
- selected `فثسف` inside surrounding text → `test`
- `wfp fodv` → `صبح بخیر`
