## What changed

- One reproducible product codebase now builds dedicated Chromium-family and Firefox packages.
- Chrome, Edge, Brave, Opera and Vivaldi use the canonical Chromium Manifest V3 package.
- Firefox uses a generated Manifest V3 package with ordered background scripts and stable Gecko metadata.
- Shared background code is compatible with Chromium worker and Firefox document/event-page contexts.
- Firefox storage, context-menu and tab-opening behavior were verified manually.
- The fragile icon → tooltip interaction was removed.
- Suggestions now use one visible correction action pill with the proposed replacement shown immediately.
- One click applies the captured range-local correction.
- Suggestion UI is isolated through closed Shadow DOM when available.
- Global host-page suggestion CSS injection was removed.
- Generated browser packages exclude development-only material and obsolete suggestion CSS.
- Existing M0/M1/M2 correction, cursor, selection, Undo, controlled-input, sensitive-field and no-submit behavior remains preserved.

## UX contract

For a wrong-layout token such as `jivhk`, the user sees the proposed correction `تهران` immediately in one isolated action pill. A single click applies the correction without automatically submitting the host page.

There is no second-stage tooltip.

## Scope

v4.3.0 establishes tested desktop browser parity across Chrome, Edge, Brave, Opera, Vivaldi and Firefox for the current web-extension product.

OS-wide Desktop correction and Safari packaging remain outside M3.
