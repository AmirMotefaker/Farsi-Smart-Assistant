### Short description

اصلاح هوشمند اشتباه کیبورد فارسی و انگلیسی در فیلدهای متنی وب، با کنترل کامل کاربر.

### Suggested detailed description

Farsi Smart Assistant helps Persian and English users recover text typed with the wrong keyboard layout.

Core capabilities:

- Persian ↔ English keyboard-layout correction
- high-confidence inline correction in ordinary editable web fields
- custom dictionary
- per-site enable/disable controls
- Persian RTL interface
- light/dark appearance
- Google/Wikipedia helper flows
- local-first correction engine without a developer-operated keystroke API
