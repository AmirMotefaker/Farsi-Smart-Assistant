# v4.9.1 Store Privacy Disclosures

## Correction data

Supported editable-field text is processed locally. The Store-safe runtime does not transmit typed correction text or search terms to Google, Wikipedia, or a developer-operated backend.

## Browser sync

User-controlled settings may be stored with `chrome.storage.sync` and synchronized by the browser vendor.

## Current-site metadata

When the popup is explicitly opened, `activeTab` provides temporary access to the current tab URL/title/favicon for site controls.

## Developer-operated collection

- analytics: none
- advertising: none
- telemetry: none
- developer text API: none
- remote runtime JavaScript: none

Firefox built-in data declaration: `required: [none]`.
